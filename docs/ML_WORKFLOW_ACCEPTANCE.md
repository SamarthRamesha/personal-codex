# Synthetic ML workflow acceptance — 2026-11-19

A complete bounded tabular-classification fixture is in `benchmarks/ml_workflow`. It uses optional already-installed NumPy/scikit-learn/joblib, no downloads, personal data or network. See its README for exact training, test, artifact and loopback frontend commands. This is a trusted scaffold with independent tests; the live9B agent repaired existing production functions. It is not evidence that the model generated the entire application from an open-ended request.

The fixture generates missing/outlier/imbalanced/noisy synthetic observations, validates shapes/classes, engineers an interaction and clips outliers, uses reproducible stratified train/validation/test splits, and fits imputation/scaling inside cross-validation. It tunes logistic regression and a bounded forest with average precision, chooses on validation, evaluates held-out metrics, produces validation permutation importance, descriptive subgroup counts/TPRs and mean-shift data, and saves a model/report/sample/hash manifest. Trusted newly generated model artifacts reproduce predictions after reload. No uploaded pickle is loaded. The local browser page displays saved metrics, comparison and audits without a CDN or external service.

- The initial nine tests were insufficient: a subgroup example made both the correct TPR and incorrect selection-rate formula equal. Independent frontend review caught the still-wrong denominator. Three stronger contrast/invariance tests then failed against delivered code. The original tests were preserved; new independent tests were added in a fresh committed fixture baseline.
- A subsequent task exposed a planner bug: a diagnostic's unique test basename was incorrectly required as a new root-level file. The planner now preserves explicit paths and resolves unique existing/planned basename references, with six regressions; ambiguous references are not guessed.
